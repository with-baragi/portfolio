# 최원진 개인 포트폴리오

Noah 템플릿을 바탕으로 만든 GitHub 포트폴리오 과목의 첫 사이트 초안입니다.

## 현재 구성

- 최원진: 사진, 자기소개, 관심사
- 강의와 코칭: 금융 강의와 재무 코칭
- 만들어온 것: 머니플로우, 인생 체험판 소개
- 일상의 기록: 독서, 봉사, 크로스핏·등산
- 연결: GitHub, 블로그, 기존 홈페이지

## 다음에 보완할 내용

강의·코칭의 실제 사례 2건, 프로젝트별 제작 과정, 독서·봉사·운동의
구체적인 기록과 사진을 추가합니다. 현재 사례 수치나 책 제목, 봉사처 등은
임의로 작성하지 않았습니다.

## 실행

별도 설치나 빌드가 필요 없는 HTML·CSS·JavaScript 사이트입니다.
이 폴더에서 `python -m http.server 8765`를 실행한 뒤
`http://localhost:8765`에서 확인할 수 있습니다.
웹 글꼴은 Google Fonts를 사용하며, 연결할 수 없을 때는 시스템 글꼴로 표시합니다.

GitHub Pages 공개는 개발 일정에 맞춰 진행할 예정입니다.
템플릿 출처와 이용 조건은 [ATTRIBUTION.md](ATTRIBUTION.md)에 정리했습니다.
