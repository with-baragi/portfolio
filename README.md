# 최원진 개인 포트폴리오

교수님이 공유한 Noah 원본 HTML에 제 자료를 넣어 만든 GitHub 포트폴리오입니다. 원본의 스타일과 화면 전환을 사용하며, 한국어와 개인 사진에 맞춘 조정은 별도 스타일 파일에 두었습니다.

## 현재 구성

- 첫 화면: 두 장의 프로필 사진과 짧은 소개
- 자기소개: 일을 대하는 태도와 미래에 대한 관심
- 강의와 워크숍: 금융 강의와 캐시플로우 워크숍에서 맡는 역할
- 직접 만든 도구: 머니플로우 소개와 서비스 링크
- 일상의 기록: 위화의 『인생』에 대한 감상, 봉사·등산·운동
- 더 많은 기록: GitHub, 블로그, 바라기 미래연구소

## 실행

별도 설치나 빌드가 필요 없는 HTML·CSS·JavaScript 사이트입니다.
이 폴더에서 `python -m http.server 8765`를 실행한 뒤
`http://localhost:8765`에서 확인할 수 있습니다.
웹 글꼴은 Google Fonts를 사용하며, 연결할 수 없을 때는 시스템 글꼴로 표시합니다.

## 게시 파일

빌드 과정이 없는 정적 사이트입니다. `index.html`과 `assets/`를 같은 경로에 두면 됩니다.
`.nojekyll`을 포함했으며 모든 로컬 경로는 상대 경로이므로 GitHub Pages의 프로젝트 경로에서도 동작합니다.
게시용 ZIP을 사용할 때에는 압축을 푼 최상위에 `index.html`이 오도록 업로드합니다.

템플릿 출처와 이용 조건은 [ATTRIBUTION.md](ATTRIBUTION.md)에 정리했습니다.
